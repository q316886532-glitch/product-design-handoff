# Product Discovery Question Bank

Use this file when choosing the next clarification questions. Ask only the few questions that materially change the plan.

## Positioning

- 这个产品一句话是什么？
- 用户现在用什么替代方案解决这个问题？
- 产品要优化的核心指标是什么？
- 用户为什么会立刻需要它，而不是以后再说？

## Users And Roles

- 谁是高频用户，谁是购买/决策用户？
- 不同角色的权限和目标是否不同？
- 是否存在管理员、审核者、外部协作者或只读访客？

## Scope

- 第一版必须完成哪一个闭环？
- 哪些功能看起来有价值但会拖慢 MVP？
- 哪些场景可以先人工处理？

## Workflow

- 用户从哪里进入核心流程？
- 成功完成后用户看到什么或得到什么？
- 失败、撤销、重试、删除、权限不足时应该怎样？

## UI And Interaction

- 用户更需要高密度工作台、移动端快速操作，还是引导式流程？
- 主要操作是否需要批量处理、搜索、筛选、排序或导出？
- 哪些状态需要明确设计：空、加载、错误、成功、只读、权限不足？

## Technical

- 是否已有技术栈、部署环境、账号体系或数据源约束？
- 是否有必须集成的第三方服务？
- 哪些能力应优先采用成熟开源方案？
